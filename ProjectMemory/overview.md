# Overview — Carmen (Amor Stories)

## Purpose
Turkish UI, adult-themed interactive story / messaging app. User creates characters (photos, traits, body params) and writes chats where they can write both sides, or let the **bot** answer from rules. Around the chat sits a large "fake internet" (ad sites, social media, shop, clinic, games…) that all feed characters into chats. No AI, no server: everything is static files + localStorage. Hosted on GitHub Pages, works offline (PWA).

## Architecture
- `index.html`: skeleton (`#view`, bottom `.nav`, `#toasts`), loads all scripts in order (data first, `js/app.js` last). Inline scripts: mobile 85% UI scale, dark theme before paint.
- Global namespace `window.Stories`: `Store`, `Traits`, `Pools`, `World`, `MODS`, `Themes`, `MONIA`, `Effects`, `Emojis`, `BOT_RULES`, `FIERY`, `SYSTEM`, `Bot`, `Gallery`, `Music`, `ME_*_LINES`, places, clothes…
- `js/app.js` (~1.7 MB, ~17k lines): ONE IIFE containing every screen and all game logic. Hash router `render()` → `renderXxx()` writes `view.innerHTML`, binds events.
- Persistence: `Stories.Store` (key `amor-stories:v2`) + many small `amor-stories:*` keys (see systems/store.md).
- Local-only dev server (`tools/bot-server.ps1`) adds `/api/bot-rules` and `/api/system` to write data files back to disk.

## File map
| Path | Role |
|---|---|
| `js/app.js` | all UI + logic (see systems/*.md for line anchors) |
| `js/store.js` | localStorage state, accounts, migrations |
| `js/bot.js` | bot rule matching engine (shared with editor) |
| `js/music.js` | Web Audio generative music (no audio files) |
| `js/i18n.js`, `js/data/i18n-en*.js` | EN/TR UI translation (see systems/i18n.md) |
| `js/gallery.js` | remote "Lara Gallery" photo picker (GitHub API) |
| `js/data/*.js` | static data (traits, pools, world, mods, themes, monia events, places, effects, emojis, clothes, fiery, me-lines, bot-rules, system) |
| `js/data/photos.js`, `mod-photos.js` | GENERATED photo lists |
| `js/data/bot-rules*.js` | bot rules (~2 MB); `backupNN` files are old copies |
| `css/style.css` | Amor base design; `css/stories.css` app additions (~300 KB) |
| `css/dark.css` | GENERATED by `tools/build-dark.js` from style+stories + `dark-base.css` |
| `tools/` | build scripts, local server, bot editor (`bot-editor.html`) |
| `docs/` | user docs: BOT-KURALLARI, YEDEK-JSON (backup format), BOT-CEVAP-ONERILERI, OLAY-KITABI-EKSIKLER |
| `characters/`, `mods/`, `Music/`, `icons/` | assets (never read) |
| `sw.js` | service worker, `VERSION` bumped every release |
| `*.bat` | Windows launchers (photos build, bot editor, local edit) |

## Conventions
- Comments/UI in Turkish with emoji prefixes; section headers `/* ---------- <name> ---------- */` — grep them to navigate.
- Helpers: `S()` state, `MO()` monia state, `$()`, `esc()`, `byId()`, `save()` (debounced), `notify()`, `sheet()` (bottom sheet).
- Line numbers in these docs are approximate; always re-grep.
